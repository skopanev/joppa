# Technical writing

## Requirement

PREFER ENGLISH. Write new technical text in English according to ASD-STE100, Issue 9.
At least 80% of the sentences in each text must follow the rules below.
Russian is permitted when needed. Apply the same rules with simple, common Russian words.

Apply this requirement to agent-authored REQs, ACs, tasks, comments, decisions, descriptions, reasons, and check results.
Include task contracts, verification scope, and expected and observed results.

## Sentences and actions

- Use a maximum of 20 words in an instruction and 25 words in a description.
- Give one instruction in each sentence. Use the imperative form for instructions.
- Use the active voice. Use the passive voice only when you do not know the agent.
- Use a verb to show an action.

## Words and grammar

- Use only simple tenses. Do not use phrasal verbs.
- Use one term for one item and one meaning for each word. Do not use slang or jargon.
- Use a maximum of three words in a noun group.
- Do not omit words. Do not use contractions. Use articles where applicable.

## Paragraphs and warnings

- Give each paragraph one topic. Use a maximum of six sentences in a paragraph.
- Use vertical lists for complex text. Do not use a semicolon.
- Start a warning with a clear command or condition. Then give the risk.

## Format and object links

- Write body, description and comments in clean Markdown: headings, bullet lists and code spans.
- Write a reference to an object as a Markdown link with its title: [Title](kind:id).
- Do not write a bare kind:id or a UUID in prose. The board shows the title and opens the object.
- A Markdown link is text. Add a structural link with links when the objects are related.

## Preservation and authority

Keep intake and verbatim user text in their original language and wording.
These rules do not apply to code, commands, identifiers, quotations, logs, or verbatim user text.
Do not translate or rewrite existing REQs, ACs, history, or evidence to apply this standard.
New REQ and AC wording still requires owner confirmation under the existing process.
Preserve the exact meaning of decisions and evidence when writing new text.
Ask the owner when a policy decision is needed.

This requirement guides agent authoring. The server does not calculate a sentence compliance score or reject text by language.

Source: [ASD-STE100](https://www.asd-ste100.org/).
